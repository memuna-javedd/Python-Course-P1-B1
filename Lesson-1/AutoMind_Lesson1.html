CONCEPT 01

What Is a Variable?

A variable is a named container that holds a value so your program can use it later.

Analogy Think of a variable like a labeled jar in your kitchen. You put something inside it sugar, salt, rice and you stick a label on the front so you (or anyone else) can find it later without opening every jar. In Python, the label is the variable name, and whatever is inside is the value.

You create a variable using the = sign. This isn't "equals" like in math it means "put this value into this jar."

age = 20 # jar labeled "age" holding 20 name = "Ahmad" # jar labeled "name" holding "Ahmad" print(age) # opens the jar and shows what's inside → 20

CONCEPT 02

Naming Rules for Variables

Not every label is allowed. Python has strict rules about what a variable name can look like.

Analogy It's like naming a file on your phone. You can call it "holiday_photo", but your phone won't let you name it starting with a symbol, or reuse special system names. Python is the same some names are simply off-limits.
✓my_age
✗2age (can't start with a number)
✓_score
✗my-age (hyphens not allowed)
✓studentName
✗class (reserved keyword)

Python is also case-sensitive age and Age are treated as two completely different jars, even if that seems confusing at first.

Practice Naming Rules

💡 Hint
Check: does it start with a letter or underscore? Does it avoid hyphens?
2.Rewrite "user name" as a valid Python variable name.
💡 Hint
Spaces aren't allowed Python programmers usually replace them with an underscore.
3.Create two variables, score and Score, give them different values, and print both. What does this tell you about case sensitivity?
💡 Hint
If both print different values without errors, they're being treated as separate jars.
CONCEPT 03

Data Types Different Kinds of Containers

Not everything you store is the same kind of thing. Python has different data types for different kinds of values.

Analogy A jar for rice isn't the same as an envelope for a letter, and neither is the same as a light switch that's simply on or off. In the same way, Python uses different data types to store numbers, text, decimals, and yes/no values.

CONCEPT 04

Checking a Type with type()

If you're ever unsure what's inside a jar, Python can tell you.

Analogy type() is like shaking a jar and asking "what's inside this?" instead of guessing. Python opens it up and tells you exactly what kind of value it's holding.
age = 20 print(type(age)) # output: <class 'int'>

💡 Hint

3.Guess before running: what does type("5") return int or str? Why might Python treat it that way even though it looks like a number?
💡 Hint

CONCEPT 05

Type Conversion (Casting)

Sometimes you need to change a value from one type to another this is called type casting.

Analogy It's like currency exchange. 100 rupees and its dollar equivalent represent the same value, just in a different form you can use in a different context. int("20") takes the text "20" and converts it into the actual number 20 so you can do math with it.
age_str = "20" # this is text, not a number age_num = int(age_str) # now it's converted to an int print(age_num + 5) # output: 25

Common conversion functions: int(), float(), str(), bool() each converts a value into that type, when possible.

Practice Type Conversion

1.Convert the string "100" into an integer and add 50 to it.
💡 Hint
Wrap the string inside int() before adding.
2.What happens if you try int("hello")? Run it and read the error message carefully why does it fail?
💡 Hint
Python can only convert text to a number if that text actually looks like a number.
3.Convert 3.99 into an integer using int(). What happens to the decimal part?
💡 Hint
int() doesn't round it simply cuts off everything after the decimal point.

Quick Recap

  • Variable = a labeled jar holding a value, created with =
  • Naming rules letters/underscore to start, no spaces or hyphens, case-sensitive
  • int = whole numbers, float = decimals, str = text, bool = True/False
  • type() tells you what kind of value a variable is holding
  • Casting int(), float(), str(), bool() convert between types
